## 2. Deskripsi Sistem
Sistem Perpustakaan Mini adalah program Python berbasis terminal (CLI) untuk mengelola koleksi buku perpustakaan. Petugas dapat menambah, menampilkan, mencari, memperbarui status, memfilter berdasarkan genre, dan menghapus buku. Data disimpan dalam Array of Struct (list of dict) di memori program.
